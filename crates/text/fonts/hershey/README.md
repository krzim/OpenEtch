# Hershey fonts

The `.jhf` files here are the Hershey fonts in James Hurt's format, as distributed in
https://github.com/kamalmostafa/hershey-fonts (`hershey-fonts/*.jhf`; only the font data is used, none of that
project's GPL code). Their licence, which permits any use with these acknowledgements:

- The Hershey Fonts were originally created by Dr. A. V. Hershey while working at the U. S. National Bureau of
  Standards.
- The format of the Font data in this distribution was originally created by James Hurt, Cognition, Inc., 900
  Technology Park Drive, Billerica, MA 01821 (mit-eddie!ci-dandelion!hurt).

The font data may be converted into any other format except the format distributed by the U.S. NTIS.
